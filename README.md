# Smart File Organizer

Скрипт на Python для автоматической сортировки и наведения порядка в папке с загрузками или на рабочем столе. 

## Особенности проекта
- **Автоматизация:** за секунды раскладывает тысячи файлов по категориям.
- **Умное распределение:** сортирует картинки, документы, архивы, установщики и мультимедиа в отдельные папки.
- **Отчетность:** выводит в консоль подробную статистику о перемещенных файлах.

## Используемые библиотеки
Проект написан на чистом Python с использованием встроенных модулей:
- `os` (для работы с файловой системой)
- `shutil` (для безопасного перемещения файлов)

## Как запустить
1. Установите Python (3.x).
2. Скачайте файл `organizer.py`.
3. Запустите скрипт в терминале:
